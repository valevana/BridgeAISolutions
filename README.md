# Bridge AI Solutions Website

Multi-page business website for a fictional AI services company (Ulster University, COM109 Client-Side Development, Group 10). Built with HTML, CSS, JavaScript and jQuery.

**Live demo:** https://valevana.github.io/BridgeAISolutions/CW2ClientSide/

## Features
- Responsive layout (CSS media queries) for mobile and desktop
- Shared header and footer used across every page
- Interactive Services page: expandable service cards, hover animation and reveal-on-scroll
- Accessibility: ARIA attributes, alt text and clear navigation labels

## My role (lead developer)
Built the site foundation, shared header and footer and the Services page, organised the file structure and page linking, and set up and managed this repository.

## Run locally
Download the repo and open `CW2ClientSide/index.html` in a browser.
